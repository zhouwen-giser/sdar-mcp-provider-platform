`P2`

## Dependencies

## Objective

## Required Work

1. Add ADR freezing `runtime_deployment.reconcile` as the only external deployment lifecycle Job Type.
2. Remove/deprecate the database-preparation external Handler and constant; database preparation remains an internal Reconciler port/service.
3. Ensure package exports do not expose a second external lifecycle Handler.
4. Strengthen `PmsJobRegistry` tests so duplicate Job Types fail deterministically.
5. Update Worker documentation to describe one external job and internal database preparation.
6. Do not build Worker Production Composition in this task.
