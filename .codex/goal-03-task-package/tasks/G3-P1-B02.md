# G3-P1-B02 — Restore verify:v2 without weakening gates

## Phase

`P1`

## Dependencies

G3-P0-B01

## Objective

修复 `pnpm verify:v2` 在干净 PostgreSQL/CI 环境中的首个真实失败，保持完整历史门禁语义。

## Allowed Paths

```text
Only paths named in B01 minimal-scope recommendation
package.json (only if command wiring is the proven defect)
.github/workflows/ci.yml (only if environment setup is the proven defect)
scripts/** (only the failing gate implementation)
tests/** (only regression tests for the proven defect)
.codex/goal-03/**
```

## Forbidden Paths / Actions

```text
Unrelated modules
Deleting/skipping tests
Reducing verify:v2 command chain
continue-on-error / || true
Protocol and migration changes unless the failure proves an existing generated artifact mismatch and no frozen source changes are made
Release files
```

## Required Work

1. Reproduce the exact B01 `verify:v2` first failure locally.
2. Before editing, record the final allowed path list in `.codex/goal-03/decisions.md`.
3. Fix the root cause, not the symptom or only CI timing.
4. Add a focused regression test or deterministic validation for the failure.
5. Run the failed subcommand alone until green, then run the complete `verify:v2`.
6. Confirm no subcommand was removed or weakened.
7. Compare protocol/migration frozen files and generated locks against baseline.

## Mandatory Verification

```bash
pnpm install --frozen-lockfile
TEST_DATABASE_URL=<local-postgres> pnpm verify:v2
pnpm typecheck
pnpm lint
git diff --check
python3 .codex/goal-03-task-package/scripts/verify_no_gate_weakening.py package.json
```

## Acceptance Criteria

- The exact CI failure is reproducible before and green after the fix.
- Full `verify:v2` exits 0.
- No gate is removed, bypassed or made optional.
- A focused regression protects the root cause.
- Frozen protocol and existing migrations are unchanged.
- Changes stay within the B01-declared minimal paths.

## Evidence

Evidence includes failing subcommand, root cause, changed paths, focused regression, full verify:v2 result and gate-diff check.
