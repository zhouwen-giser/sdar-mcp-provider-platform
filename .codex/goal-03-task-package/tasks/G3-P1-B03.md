# G3-P1-B03 — Add PMS API production CI qualification job

## Phase

`P1`

## Dependencies

G3-P1-B01, G3-P1-B02

## Objective

把已经完成的 PMS API Production Composition 测试纳入独立 CI Job，同时保留 Runtime CI 与 Compose Job。

## Allowed Paths

```text
.github/workflows/ci.yml
.github/workflows/platform-merge-readiness.yml (choose one workflow, not both)
package.json (only missing non-empty command wiring)
scripts/run-pms-api-production-gate.mjs (only defect correction)
docs/review/GOAL03_CI_MATRIX.md
.codex/goal-03/**
```

## Forbidden Paths / Actions

```text
PMS API production source
PMS Worker/PM2 code
Tests unrelated to CI wiring
Migrations
Release metadata
Branch protection API mutation
```

## Required Work

1. Add an independent `pms-api-production` job using Node 22, pnpm 11.13.1 and PostgreSQL 17.
2. Run frozen install, `test:pms-api-production`, `test:pms`, `test:pms-config-e2e`, and `test:pms-migrations`.
3. Keep `runtime-ci` and `runtime-compose`; do not replace them with the new job.
4. Ensure artifacts/logs cannot expose database URLs or token fixtures.
5. Add concurrency cancellation for superseded PR commits if consistent with repository conventions.
6. Document the current Goal 03 CI matrix and explicitly state deferred Worker/PM2 production checks.
7. Run a workflow syntax validation and local equivalent commands.
