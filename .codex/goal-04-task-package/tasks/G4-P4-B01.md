## Required Work

1. Change private root Monorepo identity to:
   - name `sdar-mcp-provider-platform`;
   - version `0.1.0`.
2. Keep `@sdar/runtime` at `2.0.0-rc.1`; do not conflate Platform and Runtime versions.
3. Remove `releaseCommit: commit-containing-this-*` and stale source SHAs from Release Manifest and Handoff.
4. Use a non-circular model:
   - `candidateSourceCommit` = exact fully tested code commit before release-metadata generation;
   - Tag/merge commit is external release metadata recorded by the eventual GitHub Release, not self-referenced inside a file that changes its own commit.
5. Regenerate:
   - RELEASE_MANIFEST;
   - TEST_EVIDENCE;
   - FINAL_DELIVERY_REPORT;
   - COMPATIBILITY_MATRIX;
   - KNOWN_LIMITATIONS;
   - CHECKSUMS;
   - SBOM;
   - `.codex/handoff/platform-v0.1-final-handoff.json`;
   - Goal 04 Handoff。
   原 Goal 2/Goal 03 Handoff 作为历史工件保持不变，并在最终报告中声明不再作为 Release Authority。
6. Task summaries must distinguish:
   - Original Goal 2: 50/50;
   - PMS API Fix: 6/6;
   - Goal 03: actual count;
   - Goal 04: 9/9.
7. Preserve qualification boundaries for external SDAR and real UGV/NPC/HA resources.
8. Merge/rebase latest Goal 03 into Goal 04, rerun all final gates and push.
9. Create/update Goal 04 → Goal 03 PR, mark Ready for Review only after checks are green, request review if connector permission is available, and list manual branch-protection actions.
10. Do not merge the PR, parent PR or main; do not create a Tag.
