# G4-P1-B02 — Enforce PM2 configuration drift and product-path real E2E

## Phase

`P1`

## Dependencies

G4-P1-B01

## Objective

使在线 Runtime 在 Runtime Version、Config Revision 或 Bootstrap Checksum 漂移时受控重启，并让真实 PM2 E2E 经过正式 JavaScript Bridge、Process Manager 和 Lifecycle Manager。

## Allowed Paths

```text
packages/pm2-runtime-adapter/src/bootstrap/**
packages/pm2-runtime-adapter/src/pm2/**
packages/pm2-runtime-adapter/src/lifecycle/**
packages/pm2-runtime-adapter/test/**
tests/pm2-adapter-e2e/**
reports/evidence/G4-P1-B02-real-pm2-product-path.json
package.json
scripts/run-goal2-test-gate.mjs
.codex/goal-04/**
```

## Forbidden Paths / Actions

```text
PMS Worker production composition
Periodic scheduler
Database provisioning
Runtime business behavior
Migrations
pnpm dlx pm2
Direct child_process PM2 CLI calls
Secret values in PM2 environment
```

## Required Work

1. Add non-secret runtime fingerprints to the rendered bootstrap environment:
   - `PMS_BOOTSTRAP_CHECKSUM`;
   - `PMS_CONFIG_REVISION`;
   - `PMS_RUNTIME_VERSION`.
2. Extend PM2 observations to read only those allowlisted fingerprints from `pm2_env`.
3. Change `start()` behavior:
   - online + all fingerprints match → unchanged;
   - online + any fingerprint differs → restart with `updateEnv`;
   - existing non-online → restart;
   - missing → start.
4. Do not compare or expose Database URL, Tokens, SecretRef resolved values or complete environment maps.
5. Rewrite real PM2 E2E to instantiate `createPm2JavascriptApi()` → `Pm2ProcessManager` → `RuntimeLifecycleManager` → built Runtime.
6. Remove all `pnpm dlx pm2`, direct PM2 CLI and temporary ecosystem-file control logic.
7. Preserve isolated `PM2_HOME` and an unrelated sentinel process; prove only `sdar-runtime-*` is managed.
8. Test no-op, drift restart, crash autorecovery, stop/delete and cleanup.
9. Regenerate redacted evidence through the production path.

```bash
pnpm typecheck

git diff --check
```

## Acceptance Criteria

- Real E2E contains no `pnpm dlx`, `child_process` PM2 CLI or ecosystem bypass.
- Unchanged fingerprints produce no restart.
- Changed revision/checksum/version produces one controlled restart.
- Runtime crash is recovered by PM2 policy.
- Sentinel and non-SDAR processes remain untouched.
- Evidence contains no Secret or connection string.
