# G4-P2-B01 — Harden PMS Worker runtime configuration and composition contracts

## Phase

`P2`

## Dependencies

G4-P0-B01

## Objective

为 PMS Worker 增加完整但受限的生产 Runtime 生命周期配置、文件安全校验和 Composition 输入契约；本任务不启动 PM2、不注册 Runtime Handler、不实现 Scheduler。


## Required Work

1. Extend Worker bootstrap configuration with:
   - `PMS_DATABASE_URL_FILE`;
   - `PMS_POSTGRES_PROVISIONING_CREDENTIAL_FILE`;
   - `PMS_RUNTIME_RELEASE_ROOT`;
   - `PMS_RUNTIME_SECRET_ROOT`;
   - `PMS_RUNTIME_CONFIG_CACHE_ROOT`;
   - `PMS_PM2_HOME`;
   - `PMS_RUNTIME_RECONCILE_INTERVAL_MS`;
   - `PMS_RUNTIME_RECONCILE_TIMEOUT_MS`;
   - `PMS_RUNTIME_HEALTH_TIMEOUT_MS`.
2. Reject inline Database URL, provisioning credentials, Runtime secrets and PM2 secrets.
3. For Secret files: absolute path, regular file, no symlink, non-empty, permissions no broader than 0600 and safe parent directory.
4. For roots: absolute existing directories, no symlink, controlled permissions; Release/Secret/Cache/PM2 roots must be distinct and non-overlapping.
5. Validate bounded intervals/timeouts and preserve existing Worker lease settings.
6. Define immutable composition contracts for repositories, database preparation, lifecycle, health, identity, catalog/registry, scheduler and cleanup.
7. Document authority boundaries: Worker manages desired/observed infrastructure, not Runtime Task data; stop does not stop Runtime.
8. Add deterministic config and path-safety tests.

## Acceptance Criteria

- All required production inputs are explicit and validated.
- Inline Secret and unsafe files/directories are rejected.
- Runtime roots cannot overlap.
- Composition contracts contain no concrete infrastructure construction.
- Existing Worker behavior is unchanged until later tasks.
