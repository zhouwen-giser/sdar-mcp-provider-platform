# 本项目仿真视场调整

用户已明确在本项目扩展实现。本仓库增加了独立 CARLA 相机后端、
`simulation_adjust_view` Task-required 工具和 1.4.0／14 项精确目录。
详细部署、输入、执行及证据说明见 [专属仿真视图](simulation-view/README.md)。

能力对象为本项目管理的仿真 RGB 相机，包含明确的所有者及实际 FOV、新相机与新帧证据。
这项能力的报告固定 `eoRecognitionAffected=false`，图像来源与上游光电识别流分别标记。
光学变焦原生拒绝仍保留原结论；旧目录不接受专属仿真视图动作。

当前进度：实现与隔离验证中，尚未切换正式实例或完成现场创建相机验收。
现场 CARLA RPC 可达，服务端版本 `067529e82-dirty`。标准 0.9.15 客户端读取场景时
发生本机原生异常，车辆/相机映射未取得。服务在客户端及服务端版本不符时于读取场景前
拒绝启用，需匹配的站点 SDK、实际 episode ID 和明确车辆 Actor/角色绑定。

软件验证与现场验收分别记账；现有未知底盘占用保留，不通过变更目录绕开前驱保护。
