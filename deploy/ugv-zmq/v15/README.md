# ZMQ 1.5 部署与原图读取

现场南向固定为自驾 2.1、光电 2.3、仿真效果 1.0。`v2/source-lock.json` 固定上游 `a0be6a5` 的文档、实现与样例；旧 `v1` 合同和旧结果继续保留。部署不能按解析失败自动切换协议。

控制目录 `zmq_v1_5_0_site_control_15` 和只读目录 `zmq_v1_5_0_readonly_15` 都包含 15 项工具。只读部署不构造控制引擎或命令传输器，拒绝控制和生命周期请求；允许 SUB、7879 规划预览和独立 FramePull。SDAR 原精确绑定不会自动接受新目录。

## 配置

复制 `profile.example.json` 并填入现有 Provider、资源及 sourceSessionKey；保留 GOWM 绑定和数据库，不在启动时安装迁移。光电取帧端点默认现场值为 `tcp://192.168.2.63:5559`，可在 `components.eo.framePullEndpoint` 覆盖，设为 `null` 时明确禁用。5557 已用于仿真效果，不能复用。

运行 `pnpm zmq:contract:check`，将输出的 v2 `contractSha256` 填入只读配置的 `contractSha256`，或控制配置的 `controlSettings.contractSha256`。新南向部署必须使用新目录及匹配的合同哈希。

Provider 可增加 `frameSettings`：默认 `cacheTtlMs=300000`、`cacheMaxBytes=268435456`、`maxCacheEntries=512`、`sendTimeoutMs=1000`、`receiveTimeoutMs=2000`。缓存按容量提前淘汰；图像和缓存令牌不进入 PostgreSQL。数据库仅保存来源引用、元数据、哈希和每次读取审计。解码在独立线程执行，上限 16 MP、128 MiB 解码器预算、2 秒验证时间；原生 JPEG 上限 16 MiB。

首次协议升级可在 `observerSettings.recoveryPredecessor` 明确配置旧 `partitionHash` 和 `sessionId`。启动核对同一设备和授权绑定、确认旧会话已经结束，然后在新流记录旧数据库尾部和断档；原始旧流不改写。后续同分区故障恢复自动核实数据库尾部，不重写不确定批次。

短暂数据库故障会立即关闭控制准入，结束接收会话；Provider 主程序在 5 秒后关闭本代实例，以退出码 75 交给 Docker 重建完整接收器与执行引擎。容量、迁移或身份错误保持关闭并等待修复。重启不重派已尝试的运动命令，原未知结果及占用对账规则继续生效。

## MCP 与面板

`vehicle_zmq_get_frame` 是同步只读工具。首次传入 `resourceId`、`cameraId`、`frameId`，后续传入同一资源、返回的 `retrievalId`、`offset`；可指定 `maxBytes`，最大 262144 原始字节。每块返回 Base64、块哈希、全图 SHA256、总长度、有效期、下一偏移及原始帧引用。令牌绑定授权域、执行域、资源和指定帧，过期不会替换为当前帧。

面板沿用 HTTP 和原操作员账号。原图通过同源后端逐块校验后显示；检测框仅来自完全相同的设备、相机和帧。曝光 UTC 为 `null` 时显示未知，框缺失时只显示已知像素位置。历史报告中的帧编号可尝试读取，长期原图可用性不作承诺。

上游明确返回 `TASK_EXPIRED` 时，已登录操作员仍可查看和下载本面板原已留存的任务快照。页面和导出均标明本地来源、记录时间及证据缺失；不会改写原任务结果，也不会恢复未保存的业务对象。权限失败或未导入的任务不使用此路径。暂停、恢复、取消及人工答复继续要求有效的上游任务。

图像不补齐覆盖、发现流完整性、实际轨迹或跨重启动作结果。光学变焦、`next_follow` 仍未发布支持；`simulation_adjust_view` 保留独立后端资格。

## 候选与切换

先用只读模式部署到回环 `19110/19111`，Provider 使用独立回环 gRPC 端口。检查端口已空闲，保留现有数据库卷、账号、绑定、PMS 配置及轨迹签名密钥。连续采集至少 24 小时的实例身份、重启计数、内存、归档和读取健康证据；发生 OOM 不能通过。

使用 `python3 scripts/ugv-zmq/v15-stability.py --config <本地监控配置> --output <新运行目录>` 采集每分钟健康与资源样本、每十分钟的精确帧校验。配置固定回环 MCP 19110、面板 19111 的 `/health/ready`，并提供预期容器 ID/镜像 ID、`resourceId` 和镜像源码版本。`durationSeconds` 至少 86400；`--once` 仅作诊断，不能通过稳定性门禁。样本按 SHA256 串联，摘要分别报告稳定性和南向数据准入；替换容器或重启会使本次连续运行失败。配置不含操作员凭据。监控只调用状态、能力和取帧接口，不会启动或变更任务。

门禁和稳定性通过后，检查正式任务、未确认派发、占用和租约，停止并锁定旧写端，使用新的交接凭据切换 `19100/19101`。条件不满足时保留候选并记录阻塞。回退使用相同新南向协议的只读配置和已固定镜像，保留任务、观测、结果和审计。旧协议镜像不能读取当前现场。
