# Change Policy

The target V1 contract permits additive optional fields, additive endpoints backed by complete SMPP source evidence, and non-semantic clarifications. Removing endpoints or response fields, making optional input fields required, narrowing enums, changing success status codes, changing business error status codes, changing concurrency inputs, or adding mandatory authentication is breaking.

The `breaking-baseline` preserves the Candidate 2 semantic reference used to reconcile Candidate 3. Candidate 3 is frozen as the formal V1 baseline and is bound by `contract-lock.json`.
