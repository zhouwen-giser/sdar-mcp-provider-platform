# 路线预览场景准入修复（2026-11-13）

## 目标与范围

用户报告 `UGV_PLANNER_SCENE_UNAVAILABLE`，并确认现场已切换 `yuan_qu`。仅修改 SMPP 隔离工作树；仿真端、SDAR 和主目录保持只读。现场运动仍须操作员确认。

## 已核实的原因

正式部署的场景及 ENU 参考已是 `yuan_qu`。三个实时 GNSS 转换样本均匹配配置。上游场景接口将整体 `DEGRADED` 映射为 `failed`，即使其新鲜运行状态仍明确开放 `scene`、`motion:ugv`。SMPP 1.5.1 将 `phase != ready` 与参考不可读合并，过度阻塞只读规划并给出错误的坐标诊断。

上游源码的 `RuntimeAdmission.allows` 按新鲜运行身份、`accepting_commands` 和组件组判断。`plan_route` 仅执行规划，并独立核验受控实体、世界纪元及任务上下文。本修复采用明确版本化的分项准入，不使用 HTTP 200、健康 level=0 或猜测身份代替证据。
