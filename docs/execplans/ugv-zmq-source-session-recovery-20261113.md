## 设计边界

新增的可选 `recoveryPredecessor.boundaryReason` 不改变旧配置默认行为或 MCP 工具目录。源重启处置要求前驱已 clean-close，profile/contract/component 完全一致；新接收分区记录前驱的最终 ordinal/head hash。控制写端仍由既有管理 CLI 和端点租约治理。普通断线与回退不会自动换会话或接受旧帧；Dashboard 只作为本次人工处置的旁证。
