# UGV task business source to public event mapping (`1.0-rc2` development)

`packages/vehicle-provider-core/src/task-business-contract.ts` defines the typed body and cursor types. `projectTaskBusinessFeedback` projects an already finalized, authorized Runtime event. `normalizeTaskBusinessSseNotification` parses the public SSE notification with an identity obtained from the authorized Task binding. Runtime intake validates typed `vehicle.business` Bodies before publication; invalid Bodies remain in the rejected inbox with their original envelope/hash and never become normal public data. The examples in `protocol/task-business/v1/examples/` are contract fixtures, not captured simulation traffic.

| Stage                | Authority                                                                       | Fields                                                                                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Adapter source       | Provider business Store                                                         | `sourceEventId`, `sourceSequence`, `sourceStreamId`, `sourceId=vehicle.business`, scope, `externalExecutionId`, `occurredAt` and immutable typed `rawPayload`           |
| Typed raw body       | Canonical Zod schema                                                            | Only `schemaVersion`, `kind`, `contextRevision`, `providerRecordedAt`, kind-specific `payload`; no public event ID, task/provider identity or Runtime cursor            |
| Runtime public event | Existing intake → mapping → finalization                                        | Authoritative `eventId`, `streamId`, `sequence`, `providerId`, `taskId`; existing source identity and raw payload hash remain unchanged                                 |
| SDK projection       | Verified Task/Execution binding plus finalized event or public SSE notification | `messageId=eventId`, `resumeFrom={streamId,afterSequence:sequence}`, separate `sourceCursor={sourceId,sourceStreamId,sourceSequence}`, verified identity and typed body |

The public `vehicle.business` SSE notification carries additive `sourceEventId`, `sourceStreamId` and `sourceSequence` provenance. `resumeFrom` belongs to the Runtime public stream and is built only from `streamId` and the public `sequence`. Multiple source events in one Context revision retain distinct public message IDs and sequences; consumers deduplicate by message ID and apply each object revision. Provider streams can mix tasks, so authorized task filtering may leave gaps in visible public sequence numbers.

Clocks remain separate: sensor time belongs in a typed object's observation fields and carries its declared clock domain; source `occurredAt` is the business occurrence; `providerRecordedAt` is durable Provider recording; Runtime publication time is a separate value only when the Runtime has it. A simulator-relative clock must not be formatted as UTC. This mapping does not synthesize absent sensor timestamps.

The old `vehicle.execution`, `vehicle.health` and `vehicle.target` streams remain readable as legacy facts. Only `vehicle.business` with `eventType=vehicle.business.changed` enters the typed task-business reducer. If one typed BUSINESS_EVENT mirrors a legacy event, its optional `legacyAlias` identifies the exact legacy source event; consumers display one occurrence and still process independently versioned Action/Artifact changes. Legacy strings never authorize commands or create typed objects by inference. Replay and refresh are read-only.

An unrecognized `kind` with `required:false` and the current schema version is retained as opaque JSON by the public projector. It creates no Action, Artifact or command. An unrecognized required kind, a known kind disguised as an optional extension, and another schema version are rejected. The generated optional-extension JSON Schema excludes known kinds; the canonical parser remains the semantic authority.

The source fixture has no trusted public identity. The public fixture adds the identity supplied after Task binding and uses a different public stream/sequence. Both fixtures are synthetic contract examples. The UGVB-020 isolated PostgreSQL and HTTP SSE test proves the local chain with an Adapter test double and an authorized Task row; selected GOWM simulation, external SDAR consumption and release remain unverified.
