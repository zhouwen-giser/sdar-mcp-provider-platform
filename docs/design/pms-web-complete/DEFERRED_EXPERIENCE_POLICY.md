# Deferred Experience Policy

A Deferred page is a complete product experience, not a placeholder. It contains realistic metadata, validation, impact analysis, navigation, and a disabled execution control with a precise Console API V1 reason.

Deferred areas include Provider Package registration/import, Runtime upgrade and Release management, Database Profile management, Registry manual publish, and other surfaces absent from the frozen contract. They never report a simulated backend success and never add a Gateway method pretending to be an API.

FORBIDDEN capabilities—Secret value access, arbitrary Catalog editing, Registry document editing, independent RuntimeProcess control, real token generation, and backend Incident/Approval persistence—are not implemented.
