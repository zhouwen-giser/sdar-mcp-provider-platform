stage-3-only policy activation are implemented. See
`docs/protocol/UGV_TASK_BUSINESS_PROVIDER_AUTO_LOCK.md` for the eligibility,
one-selection-per-mission, journal recovery and pause/cancel rules.

Twenty-five synthetic Runtime tests pass in
`tests/integration/ugv-provider-auto-lock.test.ts`; they cover requested versus
active, missing/old/retained mission identity, target loss, timeout/rejection,
uncertain dispatch, restart and control races. The existing Runtime regression
also passes. No new public track Task or weapon action is involved.

The public Profile and production boot gate stay closed because the current real
recon sources have no qualified mission identity. V-OBS/V-INPUT and selected
GOWM recovery are still required; this card is not DONE.

UGV_AUTO_LOCK_MISSION_REPLACED. This does not claim physical release. The
Runtime regression also verifies that an old coordinator invocation and old
mission stage-3 packet cannot affect the new request or input.
