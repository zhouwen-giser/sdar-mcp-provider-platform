## Wire-level capture requirements

- Capture `tools/list` names, descriptions, input schemas and output/result schemas for every required and optional tool.
- Capture success, business rejection, malformed result, timeout-after-dispatch, disconnect, reconnect and circuit recovery behavior.
- For every MQTT topic record broker URL class (redacted), wire mode, QoS, retained flag, payload bytes, decoded field names/types/units, frequency, source timestamp, source sequence/revision, reconnect/reset semantics and configured entity identity.
- Required topics: `status/ugv`, `/ugv/gnss`, `/ugv/speed`, `/ugv/mission_state`, `/ugv/nav_state`, `/ugv/system_state`, `/ugv/component_status`, `/ugv/battery_range_km`, `/ugv/area_recon/status`, `/ugv/area_recon/targets`, `/ugv/area_recon/coverage`, `/ugv/area_recon/exception`.
- Qualification must explicitly distinguish source-authoritative ordering from the weaker ingest-order fallback.

## Physical scenario inputs

1. Point navigation with known start/end coordinates and independently measurable displacement.
2. Distance navigation with requested distance, speed limit, stationary completion and tolerance evaluated outside Provider.
3. Duplicate, stale and reordered mission/position/speed packets around terminal state.
4. Pause ACK before physical pause, Resume while stationary/planning, Cancel followed by fresh stop.
5. Emergency stop while moving, while recon is active, while target locked, and with missing/stale speed.
6. Recon normal completion, empty target set, fault, out-of-range, exception, lost/missing correlation and cancel.
7. MCP read disconnect/retry recovery and mutating timeout with observation-only reconciliation.

## Deferred roadmap dependencies

- Component power: command/state contract and component inventory.
- Precise turn: angle/radius command plus heading/trajectory evidence.
- Payload brightness/focus/absolute zoom: command ranges and state feedback.
- Media capture: image/video/stream contract and Artifact service integration.
- Static engineering profile: minimum turning radius, maximum grade, obstacle height, nominal detection range and physical dimensions from engineering authority.
