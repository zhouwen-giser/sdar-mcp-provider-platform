## 文件和使用

- source.tar.gz / source.bundle：完整固定源码及 Git 历史；不含主目录未提交的联合打包工作。
- images.tar：四个固定镜像；images.json 包含 ID、源码标签、构建命令和日志哈希。
- verification/：命令、退出码、源码清单、原始测试日志和隔离取证。
- deploy/：站点控制编排与仿真视图叠加配置、操作说明。
- load-images.sh 仅载入镜像，不启动服务。

先核实 SDK、场景、车辆 Actor/角色及相机相对姿态，完成前驱占用和写端交接，
再按 deploy/simulation-view/README.md 配置新后端与 Profile。worldId 使用十进制 uint64 字符串。
保持数据库卷、账号、PMS、绑定和轨迹签名密钥；面板继续 HTTP。
SDAR 本阶段未变更，新目录需单独治理绑定，不能自动替换现有版本。
回退使用经过验证的匿名只读版本，保留所有任务、观测、报告及私有视图命令回执。
