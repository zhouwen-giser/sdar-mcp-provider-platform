## 配置要点

1. Provider 选择 `site_readonly`、部署 Profile `/2` 及协议 2.1 / 2.3 / 1.0，填入 v2 合同哈希和原绑定。FramePull 单独配置为现场 5559。
2. Runtime 沿用 `AUTH_MODE=site_anonymous`、`ALLOW_INSECURE_INTERNAL_TRANSPORT=true` 和原 JWT 校验密钥。匿名授权域仍为 default / development-anonymous；无效可选 JWT 必须拒绝。
3. 面板继续 HTTP，账号和上游凭据仅在服务端。候选使用独立本地命令域及 cookie，原域仅作为历史读取域；正式切换时恢复原本地审计域及 LAN HTTP origin。
4. 只读启动不构造控制器、不恢复控制任务、不发送设备命令。不能为了绕开断流而改成控制模式。
